# Library Management System

## Project Overview
This project is a Library Management System developed for the Python Essentials 1 practical project.

The application allows librarians to manage books and members through a menu-driven interface.

## Features

- Add new books
- Register members
- Borrow books
- Return books
- Search books
- View member summaries
- Generate library reports
- Auto-generated Book IDs and Member IDs
- Input validation using try-except
- Nested dictionaries for data storage

## Technologies Used

- Python 3
- Git
- GitHub
- Visual Studio Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python library.py

4. Follow the menu options displayed.
